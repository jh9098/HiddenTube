# Firestore 읽기 소모 체크리스트

## 기본 원칙
- 필요한 필드/문서만 읽도록 쿼리를 최소화한다.
- 전체 컬렉션 스캔을 피하고 `where`, `limit`를 우선 적용한다.
- 실시간 리스너(`onSnapshot`)는 화면 체류 중에만 유지하고 해제한다.
- 동일 데이터 재요청을 줄이기 위해 메모리 캐시/로컬 상태를 재사용한다.

## 리뷰 질문
1. 이 화면은 최초 진입 시 몇 건의 문서를 읽는가?
2. 사용자 행동(탭 전환/재렌더)마다 중복 읽기가 발생하는가?
3. 읽기 빈도를 줄일 수 있는가?
   - 페이지네이션
   - 집계 캐시
   - 쿼리 범위 축소
